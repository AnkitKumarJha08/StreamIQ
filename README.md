# 🎬 StreamIQ – OTT Data Analytics Platform

## 📊 Features
- Data Cleaning & Preprocessing
- Exploratory Data Analysis (EDA)
- Interactive Power BI Dashboard
- Content Growth Prediction (ML)
- Genre-based Recommendation System

## 🛠 Tech Stack
- Python (Pandas, Seaborn, Scikit-learn)
- Power BI
- Jupyter Notebook

## 📈 Key Insights
- Movies dominate Netflix content
- Drama & Comedy are most popular genres
- Content increased rapidly after 2015
